*School-Managment-System*

-- First Class 'Person' Is an Abstract Class that we will Inherit From it the attributes (Name, Id and Age) for Student class and Teacher Class.

-- Second Class 'Subject' Is a class that you can assign a subject with Students and its Teacher

-- Third Class 'Student' Is a Class that you can assign a student with the subjects that he must study through the semester and his Level, name, id, age.

-- Fourth Class 'Teacher' Is a Class that you can assign a teacher with his own Subject, Position and Salary depends on his Position at the School.

-- Fifth Class 'Schedule' Is used to assign a Schedule for Each Level through the Semester.

-- Sixth Class 'Report Card' Is used to assign the full information of a student's grade.

-- Seventh Class 'SchoolRegistrationSystem' Is the main Class where you apply all things we said above.
